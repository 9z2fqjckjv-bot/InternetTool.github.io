# 🌐 InternetTool

**GitHubPages で動くインターネット計測・診断ツール**

ライブサイト: <https://9z2fqjckjv-bot.github.io/InternetTool.github.io/>

---

## 概要

| 機能カテゴリ | 詳細 |
|---|---|
| ⚡ 速度テスト | ダウンロード・アップロード・Ping・Jitter の実測 |
| 🌐 ネットワーク情報 | グローバルIP・ローカルIP・IPv6・ISP・ASN・場所・回線種別・電波種別（4G/LTE/Wi-Fi/有線）・推定帯域幅・RTT |
| 💻 デバイス情報 | OS・ブラウザ・CPU・メモリ・画面解像度・バッテリー残量/充電状態・JSヒープ使用量 |
| 🔒 セキュリティ | HTTPS確認・VPN/プロキシ検出・WebRTC IP リーク検出・セキュリティスコア |
| 📡 サイト評価 | Google・YouTube・Amazon など主要10サイトの読み込み速度評価 |
| 🔧 診断・改善 | 接続問題の自動検出と改善提案（自動解決ガイド） |
| 📁 エクスポート | 全計測データを **JSON** でダウンロード、**PDF**（印刷ダイアログ経由）でダウンロード |
| 📴 オフライン対応 | Service Worker による PWA 対応。128kbps など低速回線でも動作 |

> **注意**: SSID・Wi-Fi パスワード・MAC アドレス・ルーター詳細はブラウザのセキュリティポリシーにより取得できません。取得可能な範囲の情報を表示しています。

## 使い方

### 基本操作

1. [ライブサイト](https://9z2fqjckjv-bot.github.io/InternetTool.github.io/) をブラウザで開く
2. **タブ**（上部ナビゲーション）で目的の機能に切り替える
3. 各タブの「更新」または「開始」ボタンを押して計測を実行する

### 各タブの操作

#### 📊 ダッシュボード
- ページ読み込み時に基本情報（IP・ISP・回線種別・セキュリティスコア）を自動取得
- 「🔄 全て更新」ボタンで全情報を再取得
- 「📁 JSON エクスポート」でデータを JSON ファイルとして保存
- 「📄 PDF ダウンロード」で印刷ダイアログが開き、「PDFに保存」を選択

#### ⚡ 速度テスト
1. 「▶ テスト開始」をクリック
2. Ping → ダウンロード → アップロードの順に自動測定（約30〜60秒）
3. 結果に応じた **評価グレード（A〜D）** と改善コメントが表示される
4. テスト結果は最大10件の**履歴**として保存される

#### 🌐 ネットワーク情報
- 「🔄 更新」で最新の IP・ISP・回線情報を再取得
- **グローバルIP**: 外部から見えるIPアドレス（ip-api.com 経由）
- **ローカルIP**: WebRTC 経由で取得（VPN利用時の IPリーク確認にも活用）
- **回線種別**: 4G/LTE/3G/Wi-Fi/有線などをリアルタイム表示

#### 💻 デバイス情報
- 「🔄 更新」でデバイス情報を再読み込み
- バッテリー情報は Battery Status API 対応ブラウザでのみ表示（PC の場合は「取得不可」）
- JS ヒープ情報は Chromium 系ブラウザでのみ表示

#### 🔒 セキュリティ
1. 「🔍 分析実行」をクリック
2. **セキュリティスコア**（0〜100）と各項目の状態が表示される
3. 検出されたリスクはリスト形式で表示（高・中・低リスク分類）
4. **VPN/プロキシ検出**: ip-api.com のプロキシフラグで判定
5. **WebRTC IPリーク**: VPN使用時に本来のIPが漏れていないか確認

#### 📡 サイト評価
1. 「▶ テスト開始」をクリック
2. 主要10サイトのファビコン取得時間を並行測定
3. 結果は「高速 (<200ms)」「普通 (200〜800ms)」「低速 (>800ms)」で色分け表示

#### 🔧 診断・改善
1. 「🔍 診断開始」をクリック
2. 接続状態・速度・セキュリティ・メモリなどを総合的に確認
3. 問題が検出された場合は「改善提案」として具体的な対処法を表示
4. 「📁 問題レポート (JSON)」や「📄 問題レポート (PDF)」で診断結果をエクスポート

## エクスポート機能

### JSON エクスポート
全計測データを JSON 形式でダウンロードします。以下の情報を含みます：
- タイムスタンプ
- 速度テスト結果（DL/UL/Ping/Jitter）
- ネットワーク情報（IP・ISP・場所・回線種別）
- デバイス情報（OS・ブラウザ・ハードウェア）
- セキュリティスコアとリスク一覧
- サイト評価結果
- 診断結果と改善提案

### PDF ダウンロード
印刷ダイアログを利用して PDF に保存します：
1. 「📄 PDF ダウンロード」をクリック
2. 新しいウィンドウが開く
3. 「📄 PDFとして保存（印刷）」ボタンをクリック
4. 印刷ダイアログで「PDFに保存」を選択して保存

> **ポップアップブロックが有効な場合**: ブラウザがポップアップをブロックした場合は許可してください。または `Ctrl+P` (Mac: `Cmd+P`) でこのページを直接 PDF として保存することもできます。

## オフライン対応 (PWA)

- Service Worker により、**一度アクセスすればオフラインでも動作**します
- キャッシュ済みのデータとUIはネットワークなしで利用可能
- **128kbps などの低速回線**でも動作するよう、外部依存ライブラリなしで実装
- 古いデバイス・OS（Android 5+、iOS 9+、Chrome 49+、Firefox 52+）でも動作

## 技術的制限事項

以下の情報はブラウザのセキュリティポリシーにより**取得できません**：

| 情報 | 理由 |
|---|---|
| SSID (Wi-Fi ネットワーク名) | ブラウザ API では提供されない |
| Wi-Fi パスワード | セキュリティ上、ブラウザからアクセス不可 |
| MAC アドレス | プライバシー保護のため Chrome 80+ / Firefox で削除済み |
| ルーター詳細情報 | ブラウザからのアクセス不可 |
